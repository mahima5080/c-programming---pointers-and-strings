# C Programming — Week 3: Pointers & Strings

## 📌 Topics Covered
* **Pointer Basics and Arithmetic**
* **Strings and String Functions**
* **Dynamic Memory Allocation (`malloc`, `free`)**

---

## 📁 Repository Contents
1. `1_reverse_string_pointers.c`: Reverses a string using pointer arithmetic.
2. `2_count_vowels_consonants.c`: Counts vowels and consonants in a string via pointers.
3. `3_swap_numbers_pointers.c`: Swaps two numbers using call-by-reference.
4. `4_dynamic_array_malloc.c`: Dynamically allocates memory for an array using `malloc`.
5. `word_counter.c`: **Mini Project** that counts words and characters in input text using pointers and strings.
